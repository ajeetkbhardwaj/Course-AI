## 1. Review of Computer Vision Fundamentals

The lecture begins by summarizing the core goals and challenges previously discussed:

### A. Goal of Computer Vision

* **Extract meaning from an array of numbers (pixels)**. The computer should perceive and understand the world as humans do.
* **Two primary sources of information**:
  1. **Semantic Information:** Understanding the content (e.g.,  **object recognition** , scene type, objects present).
  2. **Metric (Measurement) Information:** Quantifying spatial relationships (e.g., finding **depth** from a single image or stereo cameras).

### B. Why CNNs are Preferred over MLPs

CNNs are the preferred deep learning architecture for images because they are superior to Multi-Layer Perceptrons (MLPs):

* **Local Connectivity:** Neurons are connected only to local pixels, which makes sense since a pixel's value is highly dependent on its neighbors. This avoids the massive parameter explosion seen in MLPs.
* **Parameter Sharing:** Using the same convolution filter across the entire image provides efficient runtime, storage, and important invariances.

### C. Core Layers in a CNN

A typical CNN employs layers for feature extraction and classification:

* **Convolution (CONV):** Provides local connectivity and parameter sharing.
* **Non-linearity (ReLU):** Introduces non-linearity to the model.
* **Pooling:** Reduces the spatial size as the network gets deeper, lowering computation and increasing the receptive field.
* **Fully Connected (FC):** Used at the end for the final classification task.

## 2. The Object Recognition Task

**Object Recognition** is the first focus area of the course.

* **Goal:** Given an image, which is assumed to contain  **only one dominant object** , the task is to assign it a specific discrete label from a set of possible classes (e.g., cat, dog, truck, plane).

### Challenges in Object Recognition

The architecture must be **invariant** and **robust** to:

* **Viewpoint Variation:** Recognizing an object regardless of the camera angle.
* **Illumination Variation:** Recognizing an object under different lighting conditions.
* **Deformation:** Recognizing the same object (especially living beings) despite changes in its shape or pose.
* **Occlusion and Background Clutter:** Identifying the object even when partially hidden or surrounded by a complex background.
* **Intra-class Variations:** Recognizing that objects within the same class (e.g., different breeds of cats, different colors/styles of trucks) are the same category.

## 3. The Evolution of Deep Architectures

The effectiveness of object recognition has evolved significantly, particularly with the rise of deep learning:

* **Pre-Deep Learning Era (~2010-2011):** Shallow networks or traditional computer vision methods were used. These involved manually extracting features (like  **SIFT** ) and passing them to a classical classifier like a Support Vector Machine ( **SVM** ).
* **The Deep Learning Revolution (2012 onwards):**
  * **AlexNet (2012):** The first deep learning architecture to achieve a huge performance jump (9% error reduction) on the ImageNet Challenge. It had 8 layers.
  * **Modern Networks:** Subsequent architectures became much deeper, leading to further error reduction. Examples include **VGGNet** (19 layers), **GoogleNet** (22 layers), and **ResNet** (up to 152 layers).
  * **LeNet:** An older network that predates the modern revolution. While it existed for a long time, it was not successful on large image datasets and was often outperformed by traditional methods until AlexNet's success.

## 4. LeNet Architecture

**LeNet** is the most basic CNN architecture, primarily successful for tasks like number and letter recognition.

* It is considered a **four-layer network** because only the Convolutional and Fully Connected layers (which have weights) are typically counted for trainable parameters; Pooling layers are not.

### Architecture Breakdown

1. **Input Layer:** Takes the image input.
2. **C1 (Convolution):** Uses a **$5 \times 5$** filter with a stride of 1.
3. **S2 (Subsampling/Pooling):** Uses a **$2 \times 2$** window with a stride of 2, which effectively halves the size of the feature map.
4. **C3 (Convolution):** Another convolutional layer.
5. **S4 (Subsampling/Pooling):** Another pooling layer.
6. **F5 (Fully Connected):** A fully connected layer.
7. **F6 (Fully Connected):** The final fully connected layer leading to the output classification.
