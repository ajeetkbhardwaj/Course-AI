## 1. Object Recognition: Classical vs. Deep Learning

The goal of the object recognition task is to label a single dominant object in an image .

### A. Classical Computer Vision Approach

Traditional methods relied on **manually designed feature extraction** before classification ]:

| **Stage**                                                                                    | **Description**                                                                                                                                   | **Invariance Achieved**                                                                                                                                                                                                                          |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Initial Method**                    | Pass the raw image pixels directly to a classical classifier (e.g., logistic regression).                                                               | None. Poor accuracy due to variations (illumination, viewpoint) .                                                                                                                               |
| **Second Stage (Edges)**              | Extract the**edge map**from the image and feed it to the classifier .                      | **Color and Illumination**]. Edges typically remain the same regardless of color or lighting, simplifying the classifier's task ]. |
| **Third Stage (Histogram of Edges)**] | Calculate a histogram of the extracted edges.                                                                                                           | **Small Shifts**]. A histogram allows for some relaxation and robustness to slight shifts or misalignments of the object in the image.                                                    |
| **Later Stages**]                     | Sparse coding of the histogram, which leads to deeper and deeper levels of feature extraction ]. | Increased robustness.                                                                                                                                                                                                                                  |

### B. Transition to Deep Learning

The progression in classical methods showed a need for deeper and deeper feature extraction ]. The key difference in deep learning is that the features are **learned** instead of being manually defined ]:

* **Goal:** Allow the algorithm to find the **right features** to use, minimizing the need for human domain knowledge ].
* **Method:** Set up an **architecture** (e.g., Convolutional Neural Network - CNN) with multiple layers, and let the machine learn the optimal features at every layer through **end-to-end training** using backpropagation ].

## 2. The Neural Network Building Blocks

Deep Learning systems, like CNNs and MLPs, are built upon simple computational units: the perceptron and multi-layer perceptron.

### A. The Perceptron (Artificial Neuron)

The perceptron is the fundamental model for a biological neuron ].

* **Process:**
  1. The neuron receives **inputs** (**$X_1, X_2, ...$**) ].
  2. It performs a **weighted linear combination** of the inputs (**$W_1X_1 + W_2X_2 + ...$**) ].
  3. The result is passed through a **threshold (activation) function** to produce a binary output (0 or 1) ].
* **Functionality:** A single perceptron essentially acts as a  **linear classifier** . It defines a line, or a  **hyperplane** , in the input space that separates the data into two classes (e.g., Class 1 and Class 0) ].

### B. Linear Separability and Limitations

A single perceptron can successfully model logical operations like the **AND** gate and the **OR** gate ] because their data is **linearly separable** ].

* **The XOR Problem:** The perceptron **fails** to model the **XOR** gate because the data points for its two classes (0,0) & (1,1) for output 0, and (1,0) & (0,1) for output 1, are **not linearly separable** by a single straight line ].

### C. Multi-Layer Perceptron (MLP)

To overcome the XOR limitation and model more complex functions, the MLP was introduced.

* **Structure:** The MLP uses **multiple neurons** connected across **multiple hidden layers** ].
* **Power:** By adding just one hidden layer with a few neurons, the network can model the non-linearly separable XOR function ]. By adding more layers and more neurons, the MLP can model increasingly complex functions ].
* **Feature Extraction:** Each layer in the MLP is seen as **extracting a different level of features** from the input, starting from basic features in the first layer (like edges) and progressing to more abstract features (like contours or objects) in deeper layers ].

The video concludes by noting that while MLPs are powerful, **Deep Neural Networks (DNN)** and **Convolutional Neural Networks (CNN)** are even better suited for image-based tasks like Computer Vision ].
