## 1. AlexNet (2012)

**AlexNet** is considered the network that initiated the modern Deep Learning revolution in Computer Vision 

### A. Performance and Architecture

* **Significance:** It was the **first CNN-based architecture** to win the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) in 2012. It achieved a massive performance jump by reducing the error by **9%** over previous methods 
* **Input Size:** The input image size is fixed to **$227 \times 227 \times 3$** (RGB channels)  This fixed size is necessary because of the **Fully Connected (FC) layers** at the end, which require a fixed number of input nodes . Any input image must be resized to this fixed dimension.
* **Layer Count:** It is an  **8-layer network** , consisting of:
  * **5 Convolutional Layers (CONV)**
  * **3 Fully Connected Layers (FC)**
  * (Max Pooling and Normalization layers are not counted as they have few or no trainable parameters) 

### B. Key Features and Hyperparameters

* **Large Initial Filter Size:** The first CONV layer uses **$11 \times 11$ filters** with a stride of 4 . This large filter increases the **receptive field** (the area of the input image that the filter sees) .
* **GPU Parallelization:** Due to the low memory of GPUs at the time, the network was trained across  **two separate GPUs** , with each processing 48 out of the 96 feature maps in the initial layers .
* **ReLU Activation:** AlexNet was the **first major architecture to use the Rectified Linear Unit (ReLU)** as the non-linearity function . ReLU is preferred over sigmoid because it avoids the vanishing gradient problem and allows for much faster training .
* **Local Response Normalization (LRN):** LRN layers were used to prevent the positive ReLU values from **exploding** (becoming too large) and for performing a type of **lateral inhibition** . (Note: This technique is **no longer commonly used** in modern CNNs ).
* **Regularization Techniques:**
  * **Dropout:** Randomly drops a fraction of neurons to prevent **overfitting** .
  * **Data Augmentation:** Techniques like rotating and scaling images were used to increase the effective size of the training dataset .
* **Ensembling:** For the competition, they used an ensemble of **seven different CNN models** to combine predictions (e.g., via majority vote) to further boost performance .

## 2. VGGNet

The key idea behind VGGNet is to replace the large filters used in AlexNet with a **cascade of smaller filters** to achieve the same large receptive field while maintaining efficiency .

### A. Small Filters, Deep Network

* **Architecture:** VGGNet introduced a much deeper structure, with common variants being **VGG16** (16 layers) and **VGG19** (19 layers) .
* **Small Filter Principle:** All convolutional layers in VGGNet use tiny **$3 \times 3$ convolutional filters** with a stride of 1 and padding of 1 .
* **Achieving Large Receptive Fields:** Stacking multiple **$3 \times 3$** filters allows the network to simulate a much larger effective filter size.
  * Stacking **three **$3 \times 3$** filters** provides the same receptive field as one **$7 \times 7$ filter** .
  * This is advantageous because it introduces **more non-linearities** (due to the ReLU activation after each CONV layer) and uses **fewer parameters** .

### B. Computational Advantage (Parameter Efficiency)

The primary reason for using **$3 \times 3$** filters is efficiency :

| **Filter Configuration (C Channels)**            | **Total Parameters Required**             | **Parameter Comparison**                                                                                                       |
| ------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **One**$7 \times 7$**Filter**            | **$7^2 \times C^2 = 49C^2$**            | **$49C^2$**                                                                                                                  |
| **Three Stacked**$3 \times 3$**Filters** | **$3 \times (3^2 \times C^2) = 27C^2$** | **Almost half**the parameters (27**$C^2$**vs 49**$C^2$**) ]. |

**Conclusion:** Stacking small filters allows VGGNet to go **deeper** and be **more non-linear** while requiring a **significantly lower** number of parameters compared to a single large filter with the same receptive field ].

### C. VGG16 Architecture Analysis

VGG16 follows a simple and uniform structure: **$3\times 3$** CONV layers followed by **$2\times 2$** Max Pooling (stride 2) layers to reduce size ].

| **Layer Type**                  | **Spatial Size Change**                                                                | **Memory Dominance**                                                                                                                                                            | **Parameter Dominance**                                                                                                                                                                                                                                               |
| ------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Initial CONV Layers**         | Size is maintained (stride 1, padding 1).                                                    | **Initial layers**require the**maximum GPU memory**because the spatial size of the feature maps is still large ]. | Parameters are**relatively low**compared to FC layers ].                                                                                                                                                      |
| **Max Pooling Layers**          | Size is**halved**(stride 2) ]. | Reduces memory requirement as the network goes deeper ].                                                                      | Has**zero**trainable parameters ].                                                                                                                                                                            |
| **Fully Connected Layers (FC)** | Final feature map is flattened into a vector.                                                | Memory usage drops significantly ].                                                                                           | **FC layers dominate the total number of parameters**(e.g., 100 million parameters in a single layer) ]. The VGG16 total is 138 million parameters ]. |

### D. Generalization

* VGGNet did not use the Local Response Normalization (LRN) layer ].
* The features learned by the FC layers (specifically the **$FC7$** features) were found to **generalize very well** to other computer vision tasks (e.g., super-resolution, denoising), indicating that the network learned highly robust and meaningful representations ].
