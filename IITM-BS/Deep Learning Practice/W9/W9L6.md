## 1. GoogleNet (Inception v1)

GoogleNet, introduced in 2014, is a $22$-layer network that won the ImageNet challenge and is renowned for its efficiency and deep structure, achieved through its core building block: the **Inception Module**.

### A. Key Features

* **Depth:** 22 layers (deeper than AlexNet's 8 layers and VGGNet's 19 layers) 
* **Efficiency:** Achieved massive parameter reduction. It has only **5 million parameters**, which is:
  * 12x less than AlexNet (60 million parameters) 
  * 20x less than VGGNet (over 100 million parameters) 
* **Architecture:** The network is constructed by **stacking nine instances of the Inception Module** on top of a "stem" network (initial CONV and POOL layers) .
* **Final Layer:** It largely **removed the Fully Connected (FC) layers** typically used for classification, which were the main source of high parameter counts in previous networks like VGGNet 

### B. The Inception Module

The Inception module's core idea is to perform **parallel filter operations** of different sizes on the input feature map and concatenate their outputs . This allows the network to learn features at multiple spatial scales simultaneously.

The module combines the following parallel operations:

1. **$1 \times 1$ Convolution**
2. **$3 \times 3$ Convolution**
3. **$5 \times 5$ Convolution**
4. **$3 \times 3$ Max Pooling** (followed by a $1 \times 1$ CONV)

The outputs from all these branches are then **concatenated** along the channel dimension .

### C. The Role of $1 \times 1$ Convolution (Bottleneck Layer)

To prevent the number of feature channels (depth) and computational load from exploding, GoogleNet introduced $1 \times 1$ convolution layers .

| Feature                                                                      | Description                                                                                                                                                                                                                                                                                                                                               | Advantage |
| :--------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------- |
| **Operation**  | A filter of size$1 \times 1 \times D_{\text{in}}$ (where $D_{\text{in}}$ is the input depth) performs a dot product on a single pixel across all its depth channels.                                                                                                                                                                                  |           |
| **Function**   | It preserves the**spatial dimensions** ($H \times W$) of the input but **reduces the depth** (number of channels or feature maps), acting as a **bottleneck layer** .                                                                                                         |           |
| **Result**     | By performing dimension reduction, the$1 \times 1$ CONV layer dramatically **reduces the computational complexity** of the subsequent (and larger) $3 \times 3$ and $5 \times 5$ convolutions .                                                                                       |           |
| **Auxiliary Classifiers**                                              | To aid in training the extremely deep network and combat the**vanishing gradient problem**, smaller **auxiliary classifiers** were introduced in the middle of the network. These are only used during **training** and are disconnected during **inference** (testing) . |           |

## 2. ResNet (Residual Network)

ResNet, introduced in 2015, established a new paradigm by achieving extraordinary depth (up to 152 layers) using its defining feature: the **Residual Block**.

### A. The Challenge of Depth

In plain CNNs (without residual connections), stacking deeper layers often leads to a **degradation problem**. Beyond a certain depth (e.g., 20 layers):

* **Training error increases**: A deeper model should theoretically be able to perform at least as well as a shallower model (by simply learning the identity function for the extra layers), but this does not happen in practice.
* **Optimization problem:** The root cause is the **vanishing gradient problem**, where the error gradient fails to backpropagate effectively through many layers to update early weights.

### B. The Residual Block (Identity Mapping)

The ResNet architecture solves the degradation problem by introducing a **shortcut** or **skip connection** across the layers.

* **Structure:** An input $\mathbf{x}$ is passed through a few convolutional layers (that compute a function $F(\mathbf{x})$) and is simultaneously added directly to the output of those layers.
  * **Output:** $\mathbf{H}(\mathbf{x}) = \mathbf{F}(\mathbf{x}) + \mathbf{x}$
* **Learning the Residual:** Instead of forcing the convolutional layers to learn the entire desired mapping $\mathbf{H}(\mathbf{x})$, they only need to learn the **residual mapping** $\mathbf{F}(\mathbf{x}) = \mathbf{H}(\mathbf{x}) - \mathbf{x}$.
* **Advantage:** It is generally **easier to optimize** and learn a small adjustment ($\mathbf{F}(\mathbf{x})$) close to zero than to learn a complex identity function ($\mathbf{H}(\mathbf{x}) = \mathbf{x}$) from scratch.
* **Gradient Flow:** The skip connection provides a **direct path for the gradient to flow** from the output back to the input, effectively resolving the vanishing gradient problem.

### C. ResNet Architecture and Training

* **Construction:** The full ResNet architecture is built by **stacking hundreds of these residual blocks**.
* **Downsampling/Upsampling:** Periodically, the network:
  1. Reduces the spatial size of the feature map (downsamples) using a **stride of 2**.
  2. Simultaneously **doubles the number of filters (channels)**.
* **Bottleneck Residual Block:** For very deep networks (like ResNet-50 and above), **$1 \times 1$ convolutions are used** within the residual block to reduce and then restore the channel dimension, similar to GoogleNet, to save computation.
* **Training Details:**
  * **Batch Normalization (BN):** Used after every CONV layer. BN normalizes the activations (mean 0, standard deviation 1) to stabilize and accelerate training.
  * **Initialization:** **Xavier Initialization** was used to set the initial weights, ensuring stability.
  * **Optimization:** Stochastic Gradient Descent (SGD) with momentum was used. Dropout was typically not used in ResNet due to the regularization effect of Batch Normalization.

### D. Result

ResNet successfully enabled the training of incredibly deep networks (up to 152 layers) and achieved state-of-the-art performance, demonstrating that depth is a major factor in improving accuracy, provided the optimization problem can be solved by using residual connections.
