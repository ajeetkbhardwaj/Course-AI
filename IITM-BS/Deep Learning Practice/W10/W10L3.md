This is a detailed notebook of the YouTube lecture titled **"YOLO: You Only Look Once,"** which introduces the YOLO framework as a single-stage object detector and explains its architecture and loss function.

YOLO is a highly influential architecture because it solves the object detection problem as a **single-stage regression problem** rather than a two-stage classification and localization problem, making it exceptionally fast.

The video is available here: [http://www.youtube.com/watch?v=6O3c8jgN2Uc](http://www.youtube.com/watch?v=6O3c8jgN2Uc)

---

## 1. YOLO vs. R-CNN: A Single-Stage Approach

YOLO (You Only Look Once) is fundamentally different from the R-CNN family (R-CNN, Fast R-CNN, Faster R-CNN) [[00:13](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=13)]:

| **Feature**                | **R-CNN Family (Two-Stage Detector)**                                                                                                                                          | **YOLO (Single-Stage Detector)**                                                                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Detection Pipeline**     | **Two stages** : 1. Region Proposal (Localization/Detection). 2. Classification [[00:21](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=21)].                                       | **One stage** : The network looks at the image once and predicts all bounding boxes and classes simultaneously [[00:35](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=35)].                                                       |
| **Classification Context** | **Limited** : Classification is based only on the cropped Region of Interest (RoI), potentially losing global context [[01:36](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=96)]. | **Entire Image** : The network processes the entire image for classification and localization, providing a wider context and leading to fewer localization mistakes [[01:52](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=112)]. |
| **Inference Speed**        | Slower (even Faster R-CNN relies on two complex sub-networks).                                                                                                                       | **Much Faster**(highly popular for real-time systems) [[01:47](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=107)].                                                                                                               |

## 2. The YOLO Framework (Four Steps)

YOLO frames object detection as a regression problem. The process can be broken down into four steps [[02:05](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=125)]:

### Step 1: Split the Image into a Grid

The input image is divided into an **$S \times S$ grid** (or cells). The default value used is **$7 \times 7$** (**$S=7$**), resulting in 49 cells [[02:51](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=171)].

### Step 2: Bounding Box Prediction per Cell

* Each cell is responsible for predicting **$B$** bounding boxes, where **$B$** is a hyperparameter (e.g., **$B=2$**) [[03:24](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=204)].
* The total number of bounding box predictions for the image is **$S \times S \times B$** (e.g., **$7 \times 7 \times 2 = 98$** bounding boxes) [[04:50](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=290)].

### Step 3: Five Predictions per Bounding Box

For each of the **$B$** bounding boxes, the network predicts **five values** [[02:25](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=145), [03:52](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=232)]:

1. **$x, y$** : The **centroid** (center coordinates) of the bounding box, relative to the cell boundaries.
2. **$w, h$** : The **width and height** of the bounding box, typically normalized by the image size.
3. **$C$ (Confidence)** : The probability that the bounding box contains an object (i.e.,  **$\text{P}(\text{Object})$** ) [[04:06](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=246)].

### Step 4: Class Probability Prediction per Cell

Each cell predicts a conditional **class probability vector** for **$C$** classes (e.g., **$C=20$** classes for the VOC Pascal dataset) [[05:54](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=354)]:

* **$\text{P}(\text{Class}_i \mid \text{Object})$**: The probability that the object in the cell belongs to **$\text{Class}_i$**, **given** that an object is present in the cell [[07:13](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=433)].

**Final Combined Score:** The final score for a box belonging to a specific class is calculated by multiplying the confidence with the conditional class probability [[07:42](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=462)]:

$$
\text{P}(\text{Class}_i) = \text{P}(\text{Class}_i \mid \text{Object}) \times \text{P}(\text{Object})
$$

## 3. The YOLO Architecture and Output

### Network Structure

* **Input Size:** The image is resized to a fixed input size, typically **$448 \times 448 \times 3$** [[10:09](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=609)].
* **Layers:** The network features a total of **24 convolutional layers** [[10:23](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=623)].
* **Output Tensor:** The network outputs a tensor that encodes all the information (localization, confidence, and class probabilities) for every cell in a single step.

The final output size for the example $S=7$, $B=2$, and $C=20$ is:

$$
S \times S \times (B \times 5 + C) = 7 \times 7 \times (2 \times 5 + 20) = 7 \times 7 \times 30
$$

 [[11:54](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=714)]

| **Output Component**               | **Dimensions**          | **Details**                                                                                                                       |
| ---------------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **$S \times S$Grid**             | **$7 \times 7$**      | Corresponds to the spatial division of the image [[11:13](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=673)].                              |
| **Bounding Box Coords/Confidence** | **$B \times 5 = 10$** | **$B=2$**boxes, each with 5 predictions (**$x, y, w, h, C$**) [[11:28](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=688)]. |
| **Class Probabilities**            | **$C = 20$**          | Conditional probability for each of the 20 classes [[11:48](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=708)].                            |

### Post-Processing

Because YOLO produces **$S \times S \times B$** bounding boxes (e.g., 98), post-processing is required to filter out bad predictions and consolidate overlapping boxes [[08:30](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=510)]:

1. **Thresholding:** Boxes with a low Confidence score (**$\text{P}(\text{Class}_i)$**) are discarded [[08:41](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=521)].
2. **Non-Maximum Suppression (NMS):** For a single object, multiple bounding boxes might overlap. NMS selects the box with the highest Confidence score and suppresses (removes) any other highly overlapping boxes that predict the same class [[09:09](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=549)].

## 4. The YOLO Loss Function

YOLO minimizes a loss function that is a sum of squared errors, incorporating losses for coordinates, width/height, confidence, and class prediction [[14:17](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=857)].

| **Loss Component**                                            | **Description**                                                                                                      | **Weighting (λ)**                       | **Rationale for Weighting**                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Centroid Loss**(**$\Delta x, \Delta y$**)           | Square loss for the center coordinates.                                                                                    | **$\lambda_{\text{coord}} = 5$**       | The coordinate and size losses are weighted higher to give**more importance to localization accuracy**compared to classification and confidence [[20:32](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1232)].                                                                                               |
| **Size Loss**(**$\Delta \sqrt{w}, \Delta \sqrt{h}$**) | Square loss for the**square root**of the width and height [[21:57](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1317)]. | **$\lambda_{\text{coord}} = 5$**       | The square root dampens the effect of errors on large boxes but amplifies the penalty for errors on small boxes. This addresses the fact that a large error on a small box is much more significant than the same magnitude of error on a large box [[23:28](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1408)]. |
| **Confidence Loss (Object Present)**(**$\Delta C$**)  | Square loss for confidence when an object**is**present.                                                              | **$\lambda = 1$**                      | Default weighting [[21:07](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1267)].                                                                                                                                                                                                                                   |
| **Confidence Loss (No Object)**(**$\Delta C$**)       | Square loss for confidence when an object is**not**present.                                                          | **$\lambda_{\text{no object}} = 0.5$** | This loss is weighted lower because most cells are empty, and weighting the background heavily could dominate the training process [[20:53](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1253)].                                                                                                                  |
| **Classification Loss**(**$\Delta P$**)               | Square loss for the conditional class probabilities.                                                                       | **$\lambda = 1$**                      | Default weighting [[21:07](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1267)].                                                                                                                                                                                                                                   |

Conditions (Identity Functions) [16:15]:

The loss terms are computed only when certain conditions are met:

* **Object-Specific Loss:** Losses related to coordinates, size, and classification are only computed for cells where an object is present [[17:25](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1045)].
* **Bounding Box Selection:** For a cell containing an object, only the bounding box predictor (**$j$**) that has the highest **Intersection over Union (IoU)** with the ground truth box is responsible for the coordinate and size losses [[18:21](http://www.youtube.com/watch?v=6O3c8jgN2Uc&t=1101)]. This simplifies training by assigning responsibility for an object to a single predictor.
