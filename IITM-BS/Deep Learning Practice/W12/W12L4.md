## 1. Introduction to Image Deblurring

**Image Deblurring** is the task of taking a **blurred image** and restoring it to a **sharp, clean image** [[00:13](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=13)]. This is a crucial step in image pre-processing before high-level vision tasks are applied [[01:43](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=103)].

### A. Sources of Blur

Blurring occurs due to various factors during image capture [[00:25](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=25)]:

* **Camera Motion:** The camera moves (e.g., hand shake) while the shutter is open [[00:30](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=30)].
* **Object Motion:** An object moves rapidly within the scene while the image is being taken [[00:43](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=43)].
* **Defocus:** The camera lens is not properly focused on the object of interest [[00:49](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=49)].

### B. The Forward Process (Blurring Model)

The physical process of how a sharp image (**$\mathbf{I}_{sharp}$**) becomes a blurred image (**$\mathbf{I}_{blur}$**) is known as the forward model [[01:25](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=85)]:

$$
\mathbf{I}_{blur} = \mathbf{I}_{sharp} * \mathbf{P S F} + \text{Noise}
$$

* **Point Spread Function (PSF):** The PSF is a kernel that defines the blurring operation [[01:12](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=72)]. It is the image captured by the sensor when the light source is a single point of light (e.g., a tiny LED).
  * **Defocus Blur:** Has a circular or disk-like PSF [[03:09](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=189)].
  * **Motion Blur:** Often has a linear PSF due to movement in one direction [[03:14](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=194)].
* **Convolution (**$\mathbf{*}$**):** The sharp image is **convolved** with the PSF to produce the blurred image [[01:33](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=93)].

### C. The Inverse Problem

Deblurring is the **inverse problem** of recovering **$\mathbf{I}_{sharp}$** from **$\mathbf{I}_{blur}$**. Like other restoration tasks (denoising, super-resolution), this is **ill-posed** because multiple sharp images could produce the same blurred image [[02:48](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=168)]. Deep Networks are used to find the most photo-realistic solution.

## 2. LAKDNet Architecture: Challenging Transformers

The **LAKDNet** (Large-Aperture Kernel Deep Network) is a purely  **Convolutional Neural Network (CNN)** -based model designed to rival the performance of modern Transformer-based models, which had previously surpassed CNNs in restoration tasks [[04:07](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=247)].

### A. Motivation: Receptive Field

Transformers achieve high performance due to their  **self-attention mechanism** , which provides a **global receptive field** (allowing every pixel to interact with every other pixel in the image) [[04:54](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=294)].

LAKDNet's core contribution is demonstrating that a CNN can achieve a similarly large receptive field and comparable performance by using **large convolution kernels** within an efficient architecture [[05:12](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=312)].

### B. Overall Structure

The architecture is a hierarchical, **U-shaped structure** (similar to U-Net) with four resolution levels [[05:27](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=327)]. * **Downsampling/Upsampling:** Achieved using the **Pixel Unshuffle** (downsampling) and **Pixel Shuffler** (upsampling) operations, which efficiently change image size without relying on traditional pooling or interpolation [[06:44](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=404)].

* **Global Residual Structure:** The final output is created using a skip connection, predicting a **residual** (the blur/noise component) which is added back to the original blurred input image (**$\mathbf{I}_{blur}$**) to obtain the sharp output [[06:21](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=381)].

### C. The LAKD Block (The Core Component)

The LAKD Block is the main processing unit and contains two sub-modules: **Feature Mixing** and **Feature Fusion** [[07:26](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=446)].

#### 1. Feature Mixing Module (FMM)

This module is designed for efficient, large-kernel processing by replacing standard convolution with **Depthwise Separable Convolution** [[07:53](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=473)].

| **Operation**                                                                     | **Description**                                                                                                                                                                    | **Purpose**                                                                                                                                                                          |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Depthwise Convolution**[[08:06](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=486)] | A kernel operates on each input channel**independently** . Only**spatial information**(within a channel) is mixed [[08:58](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=538)].  | This is computationally cheaper than standard convolution, allowing the use of**large kernels**for a wider receptive field [[11:08](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=668)]. |
| **Pointwise Convolution**[[09:05](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=545)] | Uses a**$1 \times 1$**kernel to convolve across all channels (channel-wise). This mixes information**between channels**[[09:11](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=551)]. | Restores channel mixing, which was lost in the depthwise step.                                                                                                                             |

* **Alternating Operations:** By alternating depthwise and pointwise convolutions (**$\text{Depthwise} \to \text{Pointwise} \to \text{Depthwise} \to \text{Pointwise}$**), the network achieves mixing of both spatial and channel information while **significantly reducing computational cost** compared to standard convolution [[11:47](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=707)].

#### 2. Feature Fusion Module (FFM)

* **Function:** Combines features from different paths using Depthwise Convolution and a **gating mechanism** (using the Gated Linear Unit, or GLU, often with the Gaussian Error Linear Unit, GELU) [[12:35](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=755)].
* **Gating:** This mechanism is similar to Channel Attention, assigning weights to different feature channels to emphasize the most important information for restoration [[13:08](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=788)].

## 3. Conclusion and Summary of Restoration

LAKDNet successfully competes with Transformer-based models, often producing comparable or superior results while being more computationally efficient. This demonstrates that a carefully designed CNN, leveraging large kernels through efficient convolution techniques, remains a state-of-the-art solution for restoration [[13:34](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=814)].

The Image Pre-processing module covered three vital restoration tasks:

| **Restoration Task**                                                         | **Goal**                                            | **Key Architecture** | **Core Principle**                                                                                                                 |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Denoising**[[14:10](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=850)]        | Remove random noise from an image.                        | **MPRNet**           | Multi-stage progressive refinement to balance global context and local detail.                                                           |
| **Super-Resolution**[[14:18](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=858)] | Upsample a low-resolution image to a high-resolution one. | **SRGAN**            | Generative Adversarial Network (GAN) and Perceptual Loss to enforce photo-realism and overcome the blurring of Mean Squared Error (MSE). |
| **Deblurring**[[14:26](http://www.youtube.com/watch?v=Y0598h8MV6Y&t=866)]       | Remove motion or defocus blur.                            | **LAKDNet**          | Depthwise separable convolution with large kernels to maximize the receptive field while minimizing computation.                         |
