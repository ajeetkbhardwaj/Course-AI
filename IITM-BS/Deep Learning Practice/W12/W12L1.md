## 1. Introduction to Image Pre-processing

**Image Pre-processing** (or Image Restoration) is a crucial step to address image degradation before applying high-level Computer Vision (CV) tasks like recognition or depth estimation [[00:42](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=42)].

### A. Common Degradations

The presence of degradation can cause CV algorithms to fail [[01:02](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=62)]. Common forms include:

* **Noise** (e.g., from low-light conditions)
* **Low Resolution**
* **Blurring**

### B. Sources of Noise [[01:43](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=103)]

1. **Photon (Shot) Noise:** Due to the **non-deterministic** nature of light; the number of photons reaching the sensor is a random variable [[02:37](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=157)].
2. **Read Noise:** Primarily caused by **thermal activity** within the camera sensor [[03:16](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=196)].
3. **Quantization Noise:** Introduced during the conversion of the sensor's analog measurement (voltage/photons) into a digital signal [[03:39](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=219)].

### C. Image Formation Model (Denoising)

The goal of denoising is to reverse the degradation process [04:47].

$$
\text{Noisy Image} (y) = \text{Clean Image} (x) + \text{Noise} (n)
$$

The simplest model assumes Additive Noise (e.g., Gaussian noise with zero mean) is added to the clean image [04:16]. Denoising aims to estimate $x$ from $y$.

## 2. Limitations of Standard U-Net for Restoration

While the U-Net architecture is generally effective for image-to-image tasks, it has limitations in high-fidelity image restoration (like denoising) [[06:40](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=400)]:

* **Loss of Detail:** The **encoder** section of U-Net performs aggressive **downsampling** (pooling) to increase the **receptive field** and extract high-level context [[06:57](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=417)].
* **Context vs. Detail Trade-off:** While a larger receptive field is necessary for context, repeated downsampling leads to a loss of **low-level spatial detail** [[07:18](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=438)]. This results in less sharp, sometimes blurry, restored images.

## The **MPRNet** architecture is designed to overcome this by combining context-aware deep pathways with detail-preserving high-resolution pathways [[08:14](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=494)].

## 3. MPRNet Architecture: Multi-Stage Progressive Restoration

MPRNet (**M**ulti-stage **P**rogressive **I**mage **R**estoration  **Net** ) is a generic framework used for multiple restoration tasks (denoising, deblurring, deraining). Its core principle is **Progressive Refinement** across multiple stages [[08:32](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=512)].

### A. Overall Structure

The network consists of multiple stages (e.g., Stage 1, Stage 2, Stage 3) that progressively restore the image. Key features:

* **Parallel Input:** The degraded input image is fed to all stages in parallel [[09:16](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=556)].
* **Progressive Refinement:** The intermediate restored features from an earlier stage (e.g., Stage 1) are passed forward and **concatenated** with the features of the subsequent stage (e.g., Stage 2) [[08:45](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=525)].
* **Hybrid Pathways:** Each stage utilizes a combination of two sub-networks: an **Encoder-Decoder block** (for deep context) and an **Original Resolution Sub-network (ORS)** (for local detail) [[09:41](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=581)].

### B. Sub-Networks and Modules

#### 1. Encoder-Decoder Block (Deep Context) [[10:11](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=611)]

* This is a standard U-Net-like structure but incorporating a **Channel Attention Block** in the skip connections.
* **Goal:** To extract strong **contextual features** (global information) using downsampling and deep processing [[10:24](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=624)].

#### 2. Channel Attention Block (CAB)

* **Function:** Determines the **importance of each feature channel** [[11:07](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=667)].
* **Mechanism:** It summarizes channel information using global pooling (Max Pooling and Average Pooling) to create a context vector. This vector is then passed through a Multi-Layer Perceptron (MLP) and Sigmoid to generate channel weights (attention map). These weights are multiplied (modulation) with the original features to **enhance informative channels** and suppress less useful ones [[13:08](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=788)].

#### 3. Original Resolution Sub-network (ORS) [[14:22](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=862)]

* **Goal:** To process features **without any downsampling** to fully **preserve local resolution and details** [[14:36](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=876)].
* **Architecture:** Consists of multiple  **Original Resolution Blocks (ORB)** , which primarily use convolution and channel attention mechanisms at the original image resolution [[14:50](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=890)].

#### 4. Cross-Stage Feature Fusion (CSFF) Module

* **Function:** Connects features across different progressive stages [[15:31](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=931)].
* **Mechanism:** It takes features from the encoder/decoder of one stage and combines them with the input features of the next stage (e.g., ORS) via **$1 \times 1$** convolution and addition [[16:17](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=977)]. This reduces information loss and ensures richer feature enrichment as the features propagate [[16:28](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=988)].

#### 5. Supervised Attention Module (SAM) [[17:08](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1028)]

The SAM is responsible for the **restoration** and **supervision** at each stage.

* **Restoration Path:** Takes the processed feature (**$\mathbf{F}_{in}$**) and adds it (via a residual connection) to the degraded image (**$\mathbf{I}_{deg}$**) to generate the **Restored Image** (**$\mathbf{I}_{res}$**) [[17:48](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1068)]. This restored image is immediately supervised against the ground truth.
* **Attention Path:** Generates an **Attention Map** by passing the restored image through convolution and sigmoid. This map is multiplied with the original features, suppressing less informative features and allowing only the useful ones to propagate to the next stage [[19:00](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1140)].
* **Supervision:** Provides **ground truth supervisory signals** for progressive image restoration at every stage, ensuring better gradient flow and training stability [[20:07](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1207)].

## 4. Loss Function

MPRNet minimizes a combined loss function that enforces image similarity and edge sharpness across all stages.

### A. Residual Learning

At each stage, the model predicts a Residual Image ($\mathbf{R}_{res}$) rather than the entire restored image [20:30].

$$
\mathbf{I}_{res} = \mathbf{I}_{deg} + \mathbf{R}_{res}
$$

This focuses the network on learning only the difference (noise or blur) between the degraded and clean image, which is generally easier to train.

### B. Loss Components [[21:26](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1286)]

The total loss is calculated using two components and is applied to the restored image at **all three stages** of the network [[21:48](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1308)].

1. **Charbonnier Loss (Pixel-wise Loss):** A robust form of **$\text{L}_1$** (Mean Absolute Error) that is less sensitive to outliers.
2. **Edge Loss:** A loss computed on the image **edges** (using the Laplacian operator **$\nabla^2$**) [[22:10](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1330)]. This is used to ensure the edges in the restored image are sharp and not blurred, as pixel-wise losses (like Mean Squared Error) often result in overly smooth outputs [[21:45](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1305)].

## 5. Experimental Results

MPRNet demonstrates state-of-the-art performance in denoising and other restoration tasks [[22:38](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1358)].

* **PSNR Metric:** The network achieves high PSNR (Peak Signal-to-Noise Ratio), a common quality metric for restoration, indicating lower residual error compared to ground truth [[22:41](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1361)].
* **Visual Quality:** Visually, the MPRNet output successfully removes noise, especially in darker regions, without sacrificing image details [[22:52](http://www.youtube.com/watch?v=bD9kCHyWsIc&t=1372)].
* **Versatility:** The generic, multi-stage architecture allows it to generalize well to other degradation types, such as deblurring and rain removal.
